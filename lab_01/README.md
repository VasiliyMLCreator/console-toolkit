# Лабораторная работа. Консольный набор утилит

Пакет для Python 3.10 и новее. Калькулятор и конвертер не требуют сторонних библиотек во время работы.

## Установка и проверка

Из корня репозитория:

```bash
python -m venv .venv
source .venv/bin/activate
cd lab_01
python -m pip install '.[dev]'
python -m pytest
ruff check .
python -m toolkit --help
```

На Windows виртуальное окружение активируется командой `.venv\Scripts\activate`.

## Команды

```bash
python -m toolkit calc "2 + 3 * 4"
python -m toolkit calc "-(2 + 3) * 4"
python -m toolkit calc "-7 // 3"
python -m toolkit calc "7 % -3"
python -m toolkit convert 1 --from km --to m
python -m toolkit convert 32 --from F --to c
python -m toolkit convert -273.15 --from c --to k
python -m toolkit --help
python -m toolkit calc --help
python -m toolkit convert --help
```

Результаты этих вычислений: `14`, `-20`, `-3`, `-2`, `1000.0`, `0.0`, `0.0`.
Успешная команда возвращает код 0. Ошибки выводятся в stderr, код завершения — 2.

## Калькулятор

Поддерживает целые и десятичные числа, в том числе `.5` и `5.`, операторы `+`, `-`, `*`, `/`, `//`, `%`, унарные знаки и вложенные скобки. Десятичный разделитель — точка; экспоненциальная запись в выражениях не поддерживается. Пробелы, табуляции и переводы строк между токенами игнорируются, но `1 2` не превращается в `12`.

Приоритеты: скобки, унарные знаки, `* / // %`, затем `+ -`. Бинарные операции одного приоритета выполняются слева направо. `2 * -3`, `2--3` и цепочки унарных знаков допустимы; `2 ** 3` и `2 / * 3` содержат два бинарных оператора подряд и запрещены. Неявное умножение запрещено.

Этапы разделены: `_tokenization` создаёт токены, `_validation` проверяет числа, последовательность токенов и баланс скобок, `_conversion_to_reverse_polish_notation` рекурсивным спуском преобразует выражение в RPN, `_calculation` вычисляет RPN стеком. Например, `-(2 + 3) * 4` превращается в `2 3 + u- 4 *`. Ядро не использует ввод или вывод, динамическое выполнение кода и сторонние парсеры.

Вычисления выполняются через `Decimal` в локальном контексте с точностью 28 значащих цифр и округлением `ROUND_HALF_EVEN`: при точной середине выбирается ближайшая чётная последняя цифра. Литералы читаются точно; округление применяется к арифметическим операциям и итоговому результату, включая одиночный литерал. Фиксированного количества знаков после точки нет. Например, `0.1 + 0.2 = 0.3`, `1 / 3 = 0.3333333333333333333333333333`. Внешний контекст Decimal не изменяется.

`//` округляет частное вниз, к минус бесконечности. Остаток `%` имеет знак делителя либо равен нулю: `-7 // 3 = -3`, `-7 % 3 = 2`, `7 % -3 = -2`. Нулевой делитель запрещён для `/`, `//`, `%`. Превышение диапазона Decimal, невозможность представить целое частное в заданной точности и чрезмерная глубина вложенности обрабатываются как ошибки.

## Конвертер

| Группа | Единицы |
| --- | --- |
| Длина | mm, cm, m, km |
| Масса | g, kg |
| Температура | c, f, k |

Регистр единиц не учитывается. Межгрупповые преобразования запрещены. Проверка абсолютного нуля выполняется до округления: минимум равен −273.15 °C, −459.67 °F или 0 K, включая преобразование единицы в саму себя. Неизвестные единицы, нечисловые значения, NaN, бесконечности и переполнение результата запрещены. Конвертер принимает экспоненциальную запись и всегда возвращает `float`. Промежуточные операции используют Decimal с точностью 28 и `ROUND_HALF_EVEN`, затем результат преобразуется в float.

Таблица загружается из включённого в пакет `src/toolkit/units.json`. Пользовательский файл задаётся через `--config`:

```bash
python -m toolkit convert 1 --from km --to m --config src/toolkit/units.json
```

Конфигурация содержит группы, единицы и строковые десятичные параметры `numerator`, `denominator`, `offset`. Переход к базовой единице группы: `(value - offset) * numerator / denominator`. Обратное преобразование: `base * denominator / numerator + offset`. Для температуры базовой единицей является градус Цельсия; поле `minimum` задаёт абсолютный ноль в исходной единице. Числитель и знаменатель положительны, все коэффициенты конечны, имена единиц уникальны и записаны в нижнем регистре. Пользовательский файл полностью заменяет стандартную таблицу.

## История

Успешные вычисления и конвертации автоматически сохраняются в `~/toolkit_history.json` — один файл в домашнем каталоге пользователя для запусков из любых папок. Путь фиксирован.

История представляет собой JSON-массив записей с командой, исходными данными и результатом. Результаты калькулятора хранятся строками для сохранения точности Decimal, результаты конвертера — JSON-числами. Ошибочные операции и вызовы справки в историю не записываются.

Обычный запуск с сохранением результата:

```bash
python -m toolkit calc "0.1 + 0.2"
```

Флаг `--no-history` отключает историю для текущего запуска. Он указывается перед подкомандой:

```bash
python -m toolkit --no-history calc "0.1 + 0.2"
python -m toolkit --no-history convert 1 --from km --to m
```

С этим флагом файл истории не читается, не создаётся и не изменяется.

Запись выполняется заменой файла после подготовки полного JSON. Повреждённая история остаётся нетронутой, а команда завершается ошибкой. Если сохранить результат невозможно, CLI выводит ошибку в stderr и возвращает код 2. История рассчитана на последовательные запуски; одновременная запись несколькими процессами не поддерживается. Сохранение выполняется только в CLI, вычислительное ядро файлов не создаёт.

## Python API и тесты

```python
from toolkit import Calculator, Converter

result = Calculator()("(2 + 3) * -4")
converted_result = Converter()(100, "cm", "m")
```

`Calculator` возвращает Decimal, `Converter` — float. Ошибки предметной области наследуются от `GeneralApplicationErrorClass`; деление на ноль вызывает `ZeroDivisionError`.

Тесты ядра вызывают классы непосредственно. Отдельные тесты CLI запускают `python -m toolkit` и проверяют stdout, stderr, коды возврата, справку и JSON-историю. Тесты включают позитивные и негативные сценарии всех обязательных команд и дополнительных заданий.
